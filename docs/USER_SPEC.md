# Руководство пользователя Net Protector

## 1. Введение

Net Protector — система активной защиты веб-ресурсов с использованием машинного обучения для обнаружения и блокировки бот-трафика и аномальной активности.

### 1.1. Назначение системы
- Защита веб-приложений от бот-атак и DDoS
- Мониторинг трафика в реальном времени
- ML-классификация запросов (бот/человек)
- Управление пользователями и агентами защиты

### 1.2. Основные возможности
- Регистрация и авторизация пользователей (JWT + 2FA)
- Управление API-токенами для внешних приложений
- Загрузка больших файлов (до 10 ГБ) с проверкой контрольной суммы
- Панель мониторинга с графиками трафика и угроз
- Админ-панель для управления агентами и ML-моделями

## 2. Начало работы

### 2.1. Регистрация
1. Получите ключ приглашения у администратора
2. Перейдите на страницу регистрации: `https://<your-domain>/register`
3. Заполните форму:
   - Email
   - Имя пользователя (мин. 3 символа)
   - Пароль (мин. 8 символов)
   - Ключ приглашения
4. Нажмите "Зарегистрироваться"

**Примечание:** Для регистрации администратора используйте мастер-ключ: `NP-MASTER-2026-SUPER-ADMIN`

### 2.2. Вход в систему
1. Перейдите на `https://<your-domain>/login`
2. Введите email и пароль
3. Если включена 2FA — введите код из email или TOTP-приложения
4. Нажмите "Войти"

**Альтернативный вход:** Через OAuth (Google, GitHub)

## 3. Основные разделы

### 3.1. Дашборд (`/dashboard`)
Отображает статистику по вашему трафику:
- Количество запросов за последний час
- Заблокированные запросы
- Обнаруженные боты
- Список подключённых агентов

**Для администраторов:** Клик на пользователя открывает детальную страницу метрик.

### 3.2. Профиль (`/profile`)
Управление личной информацией:
- **Информация:** просмотр email, username, роли, статуса 2FA
- **Смена пароля:** обновление пароля с завершением всех других сессий
- **Активные сессии:** просмотр и завершение сессий на других устройствах
- **Аватар:** загрузка изображения (JPG, PNG, WebP, GIF, макс. 5 МБ)

### 3.3. API-токены (`/tokens`)
Создание токенов для внешних приложений:
1. Введите название токена (например, "Мобильное приложение")
2. Нажмите "Создать"
3. **Важно:** Скопируйте токен сразу — он отображается только один раз!

**Использование токена:**
```bash
curl -H "Authorization: Bearer YOUR_TOKEN" https://<your-domain>/api/v1/users/me
3.4. Загрузка файлов (/upload) — только для администраторов
Загрузка больших файлов (до 10 ГБ):
Выберите файл
Нажмите "Начать загрузку"
Файл разбивается на чанки по 10 МБ
После загрузки проверяется SHA-256 контрольная сумма
3.5. Админ-панель (/admin) — только для администраторов
3.5.1. Управление агентами
Создание агентов и привязка к пользователям
Удаление агентов
Просмотр статуса (онлайн/офлайн)
3.5.2. Ключи приглашения
Генерация новых ключей для регистрации пользователей
Просмотр истории ключей (активные/использованные)
3.5.3. ML-модели
Загрузка новых моделей (файлы .pkl и _scaler.pkl)
Удаление неиспользуемых моделей
Настройка модели и порога чувствительности для каждого пользователя (на странице метрик пользователя)
4. API Reference
Полная документация API доступна через Swagger UI:
Swagger UI: https://<your-domain>/docs
ReDoc: https://<your-domain>/redoc
OpenAPI JSON: https://<your-domain>/openapi.json
4.1. Основные эндпоинты
Аутентификация
POST /api/v1/auth/register — регистрация
POST /api/v1/auth/login — вход (возвращает JWT)
GET /api/v1/auth/oauth/{provider}/login — OAuth вход (google, github)
Пользователи
GET /api/v1/users/me — получить текущего пользователя
POST /api/v1/users/me/password — смена пароля
GET /api/v1/users/me/sessions — список активных сессий
DELETE /api/v1/users/me/sessions/{session_id} — завершить сессию
POST /api/v1/users/me/avatar — загрузка аватара
API-токены
GET /api/v1/users/me/tokens — список токенов
POST /api/v1/users/me/tokens — создать токен
Дашборд
GET /api/v1/dashboard/users — список пользователей с метриками
GET /api/v1/dashboard/user/{user_id} — детальная статистика пользователя
Админ-панель
POST /api/v1/admin/generate-invite — создать ключ приглашения
GET /api/v1/admin/invitation-keys — список ключей
POST /api/v1/admin/agents — создать агента
GET /api/v1/admin/ml-models — список ML-моделей
POST /api/v1/admin/ml-models — загрузить модель
POST /api/v1/admin/user/{user_id}/ml-settings — настроить ML для пользователя
Агент (для Go-агента)
POST /api/v1/agent/metrics — отправка метрик трафика
GET /api/v1/agent/rules — получение правил блокировки
POST /api/v1/agent/simulate-attack — симуляция атаки (для тестирования)
5. Часто задаваемые вопросы
5.1. Как включить 2FA?
Перейдите в Профиль → 2FA → Выберите метод (email или TOTP) → Следуйте инструкциям.
5.2. Как подключить Go-агент?
Администратор создаёт агента в панели управления
На сервере с защищаемым приложением запустите агент:
bash
123
Агент начнёт отправлять метрики каждые 30 секунд
5.3. Как изменить порог чувствительности ML?
Администратор → Дашборд → Клик на пользователя → Настройки ML → Выберите модель и порог → Сохранить.
5.4. Что делать, если забыл пароль?
Обратитесь к администратору для сброса пароля (функция восстановления через email в разработке).
