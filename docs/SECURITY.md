# Описание мер обеспечения безопасности Net Protector

## 1. Обзор

Net Protector реализует многоуровневую систему безопасности на всех этапах жизненного цикла приложения: от разработки до эксплуатации.

## 2. Безопасность интерфейсов взаимодействия

### 2.1. Same-Origin Policy (SOP)
**Реализация:** Браузерная политика по умолчанию.

**Как работает:**
- Скрипты с одного origin не могут взаимодействовать с ресурсами другого origin
- Предотвращает межсайтовый скриптинг (XSS) и утечку данных
